# Musafili Justine - Personal Portfolio

This is my personal student portfolio built for ICT251 Web Technologies.

## JavaScript Features Added:
1. **Contact Form Validation:** Checks name, email, and message. Shows a local preview instead of sending data.
2. **Theme Switch:** Allows the user to toggle between light and dark mode.
3. **Expandable Content:** "Read More" buttons on projects show hidden details.
4. **Study Hours Calculator:** Calculates total weekly study hours based on user input, with error validation.

## How to Test:
- Open `index.html` in a browser or use Live Server.
- Try the calculator with valid and invalid numbers.
- Try submitting the form with empty fields or an invalid email.
- Click the "Dark Mode" button in the navigation.
- Click "Read More" on any project card.
